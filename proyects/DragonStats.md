# DragonStats

Aplicacion movil para gestion y visualizacion de estadisticas de torneos de futbol. El proyecto organiza informacion de partidos, equipos, jugadores y fases del torneo en una experiencia pensada para consulta rapida y analisis visual.

## Que resuelve

- Muestra calendarios, resultados y fases del torneo.
- Facilita la consulta de equipos, jugadores y estadisticas destacadas.
- Permite marcar favoritos y conservar preferencias del usuario.

## Tecnologias principales

- Kotlin como lenguaje principal.
- Jetpack Compose para la interfaz movil.
- MVVM como arquitectura de aplicacion.
- Firebase Firestore y Firebase Auth para datos y autenticacion.
- DataStore para preferencias locales.
- Navigation Compose para navegacion entre pantallas.

## Enfoque funcional

- Navegacion por jornadas, grupos y fase eliminatoria.
- Listados y detalles de equipos, jugadores y partidos.
- Estadisticas agregadas y vista moderna adaptada a Android.
