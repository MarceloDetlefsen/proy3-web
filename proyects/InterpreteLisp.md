# InterpreteLisp

Interprete de Lisp desarrollado como proyecto academico para procesar y evaluar expresiones del lenguaje, incluyendo operaciones aritmeticas, definicion de funciones, variables, predicados y condicionales.

## Que resuelve

- Interpreta expresiones Lisp basicas de forma estructurada.
- Permite crear funciones y reutilizarlas dentro del mismo entorno.
- Sirve como ejercicio de analisis lexical, sintactico y evaluacion de expresiones.

## Tecnologias principales

- Java como lenguaje principal.
- Maven para construccion del proyecto.
- JUnit para pruebas.

## Enfoque funcional

- Lexer para tokenizacion.
- Parser para construir el arbol de sintaxis.
- Evaluator para ejecutar expresiones.
- Environment para mantener variables y funciones definidas por el usuario.
