# Simulacion de Tubo de Rayos Catodicos (CRT)

Proyecto de simulacion interactiva que reproduce el comportamiento fisico de un tubo de rayos catodicos y permite explorar visualmente como se mueven los electrones bajo diferentes condiciones electricas.

## Que resuelve

- Representa de forma didactica la trayectoria de electrones dentro de un CRT.
- Permite cambiar parametros para observar deflexion vertical y horizontal.
- Incluye modos de visualizacion manual y patrones tipo Lissajous.

## Tecnologias principales

- Python como lenguaje principal.
- Pygame para la interfaz y visualizacion.
- NumPy para calculos numericos.
- SciPy para apoyo en procesamiento y modelado matematico.

## Enfoque funcional

- Simulacion con componentes graficos e interaccion en tiempo real.
- Modelo fisico orientado a educacion y visualizacion cientifica.
- Separacion entre calculos, renderizado y controles de la interfaz.
