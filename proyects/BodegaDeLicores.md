# Bodegas de Licores

Plataforma web para la gestion y compra de productos de bodega, con experiencia separada para clientes y administracion. El proyecto cubre catalogo, carrito, pedidos, inventario, promociones y control de acceso por roles.

## Que resuelve

- Centraliza la operacion de una bodega de licores en una sola plataforma.
- Permite navegar productos, realizar pedidos y administrar inventario.
- Incluye modulos administrativos para usuarios, sucursales, promociones y seguimiento de ordenes.

## Tecnologias principales

- Frontend con Vue 3 y TypeScript.
- Vite como entorno de desarrollo y build.
- Pinia para estado global.
- Vue Router para navegacion.
- Axios para consumo de APIs.
- Clerk para autenticacion.
- Backend con Express, TypeScript y Prisma.
- PostgreSQL como base de datos.
- Cloudflare R2 para almacenamiento de imagenes.

## Enfoque funcional

- Separacion clara entre cliente y administracion.
- Control de roles y autenticacion para proteger vistas internas.
- Arquitectura orientada a escalabilidad de catalogo, pedidos y operaciones.
- Integracion completa entre frontend moderno y API REST.
