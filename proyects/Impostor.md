# Juego del Impostor

Juego web para jugar en grupo en modo local o remoto, donde los participantes reciben palabras, pistas y roles de forma dinamica. El proyecto esta pensado para partidas rapidas y sociales, con soporte para lobbies compartidos y control de anfitrion.

## Que resuelve

- Facilita partidas locales en un solo dispositivo o partidas remotas por codigo.
- Maneja categorias, turnos, revelacion de tarjetas y cierre de lobby.
- Permite coordinar dinamicas grupales sin complejidad tecnica para los jugadores.

## Tecnologias principales

- Frontend con HTML, CSS y JavaScript vanilla.
- Backend con Elysia y Bun.
- Datos en archivos CSV por categoria.
- Despliegue en Vercel y Railway.

## Enfoque funcional

- Modos local y remoto.
- Sistema de lobbies con host y jugadores.
- Flujo simple para categorias, ruleta de orden y revelacion del impostor.
- Arquitectura liviana, sin frameworks pesados en el cliente.
